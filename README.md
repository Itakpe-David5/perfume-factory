# AuraCraft Fragrances — Perfume Factory Website

This project is a multi-page website built for a luxury perfume manufacturing and wholesale brand. It was developed as part of practical tasks for my **SIWES (Student Industrial Work Experience Scheme)** program to demonstrate proficiency in web structure, HTML forms, and version control using Git and GitHub.

---

## 🌟 Features

* **Multi-Page Layout:** Seamless navigation across Home, About Us, Products, and Contact pages.
* **Responsive Design:** Clean, modern, and accessible layout styled with custom CSS.
* **Interactive HTML Forms:** A fully structured wholesale order and customer inquiry form utilizing various input types, dropdowns, and textareas.
* **Product Catalog:** Showcases signature fragrances with detailed top, heart, and base scent notes.

---

## 🛠️ Technologies Used

* **HTML5:** Semantic elements, structure, and forms.
* **CSS3:** Styling, CSS Grid/Flexbox, variables, and responsive design.
* **Git & GitHub:** Version control and remote repository management.
